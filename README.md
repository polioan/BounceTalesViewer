# BounceTalesViewer

Bounce Tales levels viewer

https://polioan.github.io/BounceTalesViewer/

1. Select level
2. Hold and move to navigate

## How I did it?

1. Unpack game using https://github.com/HelloOO7/BounceTales
2. Parse rlef levels
3. Parse res for images
4. Map data to game hard-coded seeds and textures
5. Embed computed level JSON into JavaScript
6. Draw this data to canvas
